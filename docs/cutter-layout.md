# 切膜生产硬约束

- 膜规格为 600mm 和 450mm，分别选择适合的排版策略。
- 图片保持导入方向；切膜模式禁止旋转、物理缩放及拉伸。
- 从像素及内嵌 DPI 读取打印毫米尺寸；缺少可靠 DPI 时切膜模式停止。
- 刀位可在批次开始前调整，整批固定，参数必须按设备校准。
- 右图左侧色块的左边缘横坐标整批固定，与刀位保持安全距离及可调偏移。
- 刀位两侧安全区不能被图片、标签或色块侵入。
- 并排图片的识别色块处于同一高度，满足横切一刀的限制。
- 保持输入顺序及双面配对，双面必须并排或同列上下相邻。
- 约束内优化长度，不将裁去文件的透明右边当作节省实际膜宽。

## 当前实现

450mm 默认单列，600mm 默认固定双列；450mm 小图可手动选择固定双列。
使用保持顺序的动态规划，比较单列、双列和双面同列组合的长度。
分区检测使用图片与装饰的完整占用范围，不只检查图片像素框。
固定双列只能放进各自分区，不能通过“单张占满全宽”越过固定刀位。
切膜模式将色块锁定为图片左侧顶部；自由模式可另行调整。

当前尺寸包含图片文件的完整像素画布，不自动裁掉图片内部透明边缘，
也无法单凭文件判断应用于烫压机的方向或图片 DPI 是否人为填写错误。
